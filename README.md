A tiny digital birthday gift for my sister Khushi.

2. 🧸 Our Timeline — 2005 → 2026
3. 📸 The Khushi Archive — personal photos and memories
4. 💌 Things I Don't Say Enough — sibling appreciation
5. 🃏 Memory Match — 10-card matching game
6. 🏆 Sister Awards — playful awards
7. ✉️ The Letter — personal birthday message
8. 🎂 Birthday Ceremony — lights → poppers → cake → candles → wish → cake cutting → final reveal

## Development

The project is intentionally content-driven so personal photos, captions, jokes, and the final letter can be added without changing the experience architecture.

Birthday ceremony supports a fallback interaction for candle blowing so the experience does not depend on microphone permissions.

Music will use an appropriately licensed/royalty-free birthday background track.
